## 根因与修改

1. **超时覆盖审阅**：`write_run_progress` 无条件用最后一次结果覆盖 `review-report.json`，交付评估也只取最后一次审阅。现在 `review-attempt.json` 保存最新尝试，`review-report.json` 保留最后一次有效语义审阅；交付清单保留其评分、意见和版本，同时记录最新失败。当前稿件仍按内容指纹校验，旧稿通过不代表修订稿通过。15 条历史问题仍保留在独立台账中，不把历史意见全部冒充当前有效意见。
2. **超时误判为断网**：单次调用和任务总预算共用 `TaskDeadlineExceeded(TimeoutError)`，被网络异常分支计数并进入冷却。新增 `ModelCallTimeout`，单次模型超时不污染网络状态；任务总预算耗尽单独记录 `task_deadline` 和实际停止原因。审阅在剩余预算内仅做一次精简材料重试，仍保留完整正文、原评分门槛和引用定位校验；重试失败明确停止并保留诊断。
3. **真正的命题丢失原因**：两个已有 `formal_spec` 的候选被 `mechanism_links.0` 类型校验拒绝（对象误填进字符串列表），随后核验任务仍被派发。推理入口现在无损序列化结构化链环；应用题中的显式条件理论命题可纠正 `associational/scenario` 分类，保留原类型；因果实证断言不借此变成定理。候选在生成后续需求前校验，非法候选留诊断、不派发空核验。JSON 解析失败仅追加一次格式修复调用。
4. **定义义务死锁**：实际 `Δ_eff := E[Y(1) − Y(0)]` 只存在于明确的命名陈述，`lhs/rhs` 为空。新增保守的期望命名语法，转为非强制的变量域、期望存在性及适用条件披露；不生成证明证书、不升级结论，附带性质仍须单独核验。
5. **PDF 溢出位置**：总结引用的 `while \output is active` 指向输出页的页眉，不能据此认定 `\section` 正文不可换行。CTeX 默认 `headings` 会把章节名放入页眉。统一模板显式使用 `\pagestyle{plain}`，保留页码及正文完整标题，不提高溢出阈值、不强行截短标题。[CTeX 官方源码与手册](https://github.com/CTeX-org/ctex-kit/blob/master/ctex/ctex.dtx)。
