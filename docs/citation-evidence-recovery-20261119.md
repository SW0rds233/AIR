## 获取与核验路径

1. 优先匹配 Crossref DOI JSON；不可用时尝试 CSL JSON，必要时保留题名/作者匹配及 OpenAlex 查询。
2. 缺卷期页时，定向核查可按精确 DOI 从 OpenAlex 补充缺失字段；不覆盖原日期和已核准作者。
3. 通过登记的出版原页 URL 或审阅提供的元数据页 URL 直达页面，再回退 DOI 跳转。读取 citation/DC 标签、文章级 JSON-LD 和有 DOI 的 RIS 导出，不执行网页 JS，不从正文参考文献中的 DOI 判断当前页面身份。
4. DOI 必须对应同一作品。补充字段有独立出处，旧的已核准补充值不会被聚合接口中的空字段清除。候选 URL 尚需被检索或明确提供，不承诺自动发现所有机构页面。
5. 审阅对已有书目提出 DOI/ISSN/出版身份异常时须给出逐字段核查依据。缺少依据会触发一次纠错；仍有矛盾时审阅保持未完成，不自动提分、放行或删掉真正的内容适用性问题。
