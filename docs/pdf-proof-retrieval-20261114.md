## 修复

- **统一数学规范化。** 普通正文生成的下标、上下标、显式 `$...$` 与其他数学入口共用 Unicode 转换；转换后的控制词与紧随其后的变量分隔，避免 `∈K` 变成未定义的 `\inK`。
- **编译成功必须包含完整字形。** 前言设置 `\tracinglostchars=3`；编译器读取实际 `.log`，缺字判为失败，并启用文件与行号诊断。导出阶段保留完整诊断供清单评估，界面日志尾部仍有长度限制。原有非零退出码、截断 PDF、交叉引用与严重溢出检查保留。
- **引用检查区分数学与文献。** 跳过显式数学及带区间语义的方括号，不把 0 当引用；真实引用和编号范围继续检查，范围中间的编号也不能漏查。
- **命题提交与义务同事务落盘。** 条件编码的义务按命题及版本稳定登记，重放不重复；新版本生成新义务。主循环从已提交对象恢复缺失的核验需求，解除“核验过首批就永远不再优先核验”的全局标记。已有编码目标按版本执行一次，受总预算限制，保留写作、独立审阅的执行机会。
- **核验任务不扩展旁支。** `verification_only` 缺少目标时直接给出未决诊断，不转入模型生成更多命题。已声明的有限求和/乘积只按受限记号规则登记适用条件，不当成已证结论；未知语法、未声明量或复合左端仍要求修复。附带的性质必须另立 assertion。
- **区分反证目标和空洞证明。** 显式 `A ⇒ False` 表示检查 A 不可满足；求解器确认不可满足时可关闭该目标。矛盾前提加任意普通结论仍返回 unknown。
- **双库工具路径一致。** 证据收集原本已经合并会话库与绑定库，但智能体的主动检索/原文工具默认只指向第一库。现在工具按授权策略联合查询和核读，输出来源库名，也可指定其中一库；单库失败不丢弃另一库的结果。检索覆盖记录新增每库查询、命中数、通道和失败信息。

## 双库的准确含义

| 策略 | 智能体可读取的文献库 | 新外部资料写入 |
| --- | --- | --- |
| `both` | 当前会话文献库 + 已绑定资料库 | 当前会话文献库 |
| `user_kb` | 已绑定资料库 | 不外搜 |
| `autonomous` | 当前会话文献库 | 当前会话文献库 |

这指的是文献库，不是把会话历史消息、SQLite 全表或其他会话全部塞进模型上下文。模型通过检索和原文工具取得有界片段；研究对象另由当前任务上下文提供。

## 检索能力及边界

当前代码已有问题/缺口驱动查询、中英文查询规划、arXiv / Semantic Scholar / OpenAlex 外检、关键词/卡片/可选向量召回、RRF 融合、相关性筛选、去重、出版元数据核对、开放全文获取、原文定位和独立支持关系判定。向量召回取决于嵌入配置与索引，全文取决于访问权限及下载/解析成功情况。

不能称为完备：三类外部学术索引不等于政府公告、政策、统计数据库及各付费中文库的系统覆盖；摘要不能代替方法和条件全文核读；检索、版本核查和支持判断仍有网络、预算与模型限制。此次 0 条 supports 也不能靠提高篇数纠正：形式命题应由证明支撑，产业文献只能对其对应的经验前提或机制提供证据，不能自动证明星网的现实因果效果。没有降低审阅阈值、没有把候选文献改标为支持，也没有启用人工义务或配图。

## 排版方案依据

[LaTeX 官方发布说明](https://github.com/latex3/latex2e/blob/develop/base/doc/ltnews34.tex)说明 `tracinglostchars=3` 可把缺失字形提升为错误，本轮采用这一机制并保留日志兜底。[latexmk](https://ctan.org/pkg/latexmk?lang=en)适合自动管理交叉引用和多遍构建，但不会修复送入引擎之前已漏转义的数学内容。本轮保留现有 XeLaTeX 出口，先统一内容规范化和完整性检查；没有引入未经真实环境验证的新引擎或降级渲染器。
