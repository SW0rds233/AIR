# AI for Research（AIR）统一智能体团队：重构结果与下一轮验收计划

更新：2026-10-05。本文以本目录 `AIR_new` 的当前代码为准；旧版对照、已退役入口和历史测试数量不再当成现状。

## 一、目标与系统边界

用户以自然语言提出研究方向或问题，也可以附带题面、文献、案例和数据。系统应理解问题类型、约束与授权，自主形成研究路线，在必要阶段检索与复查资料，建立模型、推导并核验条件性结论，提出可实施的仿真/实验验证建议，最后形成可追溯、可读、经审阅的论文或如实降级的研究报告。当前阶段不自动实施新实验、训练或投稿。

唯一运行结构是 `TeamRun`/`TeamSession`：一个 `SupervisorAgent` 负责画像、计划、派工、复盘与必要澄清；七个功能角色分别是 `EvidenceAgent`（文献/案例/资料）、`ModelingAgent`（问题建模）、`ReasoningAgent`（推导与结论候选）、`ValidationPlanningAgent`（仿真/实验方案）、`WritingAgent`（唯一文稿 IR）、`FigureAgent`（图表）、`ReviewAgent`（独立审阅）。子智能体提交候选与需求，不私自更改科学判定；`ResearchCommitService` 是对象、验证状态、证据冲突与失效传播的唯一提交边界。综述和理论研究是同一团队接收的不同任务，而不是两个引擎。

人工可以在会话中澄清、指定问题/对象提交反馈、要求重检索或修订、查看缺口与恢复运行；无需逐阶段审批或专家签字。系统不得因没有人工签字就阻止生成成果，但正式科研结论仍须由研究者独立复核。

## 三、当前验证事实

此前 `problem2.md` 的离线运行与一次真实模型运行已经证明团队路径可给出条件明确的非存在性结论、保留推导与正文追溯；真实模型运行 5 次模型调用、44,931 tokens，稿件追溯和出版门槛为真。但当时没有可定位文献和 XeLaTeX，因此只得到论文草稿，**不是**经过文献核验且带 PDF 的正式论文。本轮没有把这份历史结果冒充新的端到端复测。

本轮在代码清仓后重新执行 Python 全量回归、前端 258 项组件测试、TypeScript 检查与 Ruff；具体最新数量和未通过项记录在 [`docs/进度.md`](进度.md) §5。新补的图表打包是单元/集成接口测试，尚未以真实浏览器和真实模型完整验收。

## 四、下一轮仅保留尚未验证或需要加强的工作

1. **真实科研质量验收（最高优先级）**：用 `problem2.md` 和至少两道未见题（一个依赖文献、一个需建模/仿真建议），在授权检索和真实模型下跑全程；检查检索确实发生在推导前及推导中，关键定理有可回到原文的定位，反证会重新触发推理。人工逐条核对题意、适用条件、推导有效性、结论强度、参考文献真实性及正文可读性。没有来源时不得补造引用。
2. **出版物实物验收**：在提供 XeLaTeX 的环境编译含中文、公式、表格、图、引用的稿件；检查 PDF 页序、图像存在、交叉引用、参考文献唯一性与文本溢出。编译不可用或失败时继续如实降级，不能标为“完整论文”。
3. **图表与证据全流程验收**：真实生成图并确认由 FigureAgent 记录、WritingAgent 引用、交付包复制、PDF 嵌入；用多命题文献任务验证来源归属不串线。无依据或图片哈希失配时给出可见缺口，不静默丢图。
4. **浏览器与会话验收**：真实 Chromium 检查双会话事件隔离、附件题意、断线重连/续跑、对象级人工反馈后的重新推导和正文刷新、迟到事件不覆盖新会话。组件测试通过不等于浏览器通过。
5. **研究能力边界**：现有形式化工具只覆盖已实现的判定与核验类型；通用新定理发现、复杂证明、跨文献条件对齐和经验因果推断仍可能给出未决项。遇到工具不支持、文献冲突或资料授权不足，应由主控换路线、提出明确缺口或请求用户决定，不把 `unknown` 升成证明成功。
6. **历史测试语义审计**：旧引擎专属测试已从现行回归移除，当前 979 项通过不等于旧 1161 项的逐项等价证明。对旧测试中仍有科研价值的断言（例如因果条件、证据相反关系、恢复后失效传播）逐项决定保留/重写，并通过团队公共接口补回；不要复活旧引擎只为让测试通过。

## 五、人工需要完成的工作

- 指定允许使用的本地资料集/外部检索范围，提供需要核对的文献原文；若要完整 PDF，准备可用的 XeLaTeX 与中文字体环境。
- 对真实模型测试的数学推理、引用原文、图表语义、仿真/实验建议及论文逻辑作学科复核；系统的测试通过只说明软件契约通过，不替代科研审稿。
- 对任何新增的外部数据库、实验执行或投稿权限单独授权；当前实现不暗中扩大权限。

下一轮完成的判据不是“Agent 文件齐全”或“测试全绿”本身，而是：一个请求只启动一套团队；可解释地自主推进与回流；产物、证据、图与结论均有同一身份和版本链；正式论文门槛由实际编译和可定位依据决定；失败与未决如实呈现。
