## 编译根因

- **公式环境进入普通文本转义**：实际 `blk-ef28acb3.text` 含完整 `aligned` 因果链，渲染后出现 `\textbackslash{}begin{aligned}`、`\&=` 和 `$I_{t-$\tau$}$`，第 113 行报 `Missing } inserted`。因此不能只修 `math` 字段。现在正文转义和 math 拆分都先识别完整环境；保留对齐符、去除多余的内部数学切换，保留 `\text{}` 内合法行内数学，同时避免把行内 cases 嵌成展示公式。紧接 aligned 的恒等式仍处于数学模式。
- **单个浮体超页**：变量表超出页高 385.18pt；失败 PDF 第 6 页的表格确实越过页脚并被裁切。表格统一使用非浮动 `longtable`，按正文宽度计算可换行列，跨页重复表头、保留所有数据行。[CTAN longtable 文档](https://ctan.org/pkg/longtable)说明该环境支持跨页及重复页头。极端的单行自身超过一页仍需拆分内容，未在本轮自动猜拆。
- **错误摘要掩盖根因**：编译器使用 `-file-line-error`，但提取器只找 `!`，还截断日志前部。现在识别带文件名、行号及折行的错误，保留首个致命诊断；交付状态显示真正的 `Missing } inserted`，不再选取前面的引用 undefined 警告。浮体超页纳入布局阻断，longtable 列宽变化纳入有限轮次重编译。失败 PDF 继续保留为诊断件，不能冒充正常交付。
