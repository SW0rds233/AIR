# 会话资料存储

Web 端每次启动研究会生成一个会话 ID。新会话的对话与自动获取的文献位于同一目录：

```text
data/conversations/<session_id>/
├── conversation.json       # 输入快照、消息、状态、摘要，供历史回看和续跑
└── literature/
    ├── kb.sqlite           # 本会话自动检索文献的记录、原文分块、来源信息
    └── pdfs/               # 本会话实际下载的开放获取 PDF
```

`kb.sqlite` 和 `pdfs/` 只在有对应文献时创建。下载失败或仅取得摘要时，数据库可能有记录而 `pdfs/` 为空；不把摘要伪装成全文。用户在 `data/` 放置的原始文件不会被搬动。通过“从本机路径添加资料”导入的文件仍只登记引用，人工资料库保存在 `data/kb/<资料库名>/`，可以被多个会话选用。会话的自动检索结果不会写回人工资料库。

人工文献可用“从文件管理器选取文件夹”添加，也可手动填路径。输入已有库名时，导入会并入该库并保留原有文献；新文件进入同一个 `kb.sqlite`，重复文件按身份去重。导入后页面自动选中该库；若当前已有对话，`conversation.json` 会另记 `bound_source_set_id`，而该研究运行的原始输入快照保持不变。正在运行的研究继续使用启动时的资料范围，下一次研究才使用新绑定。切换回历史对话时，页面恢复该库选择。文件夹选择器只在运行 AIR 的本机弹出；明确选中的目录获得 15 分钟临时授权，扫描与导入仍逐项检查敏感文件、符号链接和数量上限。未通过选择窗口授权的手动路径继续受预设授权根限制。

旧版 `data/conversations/<session_id>.json` 可继续回看和续跑；其后再次保存时写入上述新目录。旧的 `data/pdfs/` 与 `data/kb/` 不自动迁移或删除。删除新会话时会清除该会话目录及检查点等现有会话资源；共享人工资料库和用户原始文献不在删除范围内。

Web 页面左侧的消息、附件列表和本机路径扫描预览分别滚动。扫描大量文献后，可在预览区域滚动查看条目，对话区高度不会随条目数缩小。
