## 2. 新暴露的缺陷

### R-008【严重】模型自撰 `\tag` 导致编译失败、无 PDF

```
compilation_status  failed: LaTeX 编译报错, 输出可能被截断
manuscript.log      ! Package amsmath Error: Multiple \tag.   （全文仅这一条错误）
```

**成因链**：

1. 模型在自撰的展示公式里写了编号，`manuscript.tex` 第 152/177/182/187/192 行含
   `\tag{3.4}`、`\tag{3.10}`、`\tag{3.11}`、`\tag{3.12}`、`\tag{3.13}`；
2. 渲染器把该数学块包进 `\begin{equation}`（**自带编号**）；
3. 两者冲突 → amsmath 报 `Multiple \tag`；
4. `src/publication/render_latex.py` **全文件没有任何 `\tag` 处理逻辑**（已用全文检索确认）。

**性质**：首轮该现象为 **0 次**，且本次同步**未改动 `publication/`**（只改了 `src/kb/publication.py`，另一模块）。
因此这不是本次同步引入的回归，而是**一个此前未被触发的潜在缺陷** —— 与早期那批"模型自撰 LaTeX 构造未被转义"的缺陷同族
（`^`、`\#`、`~`、Unicode 符号都曾以同样方式暴露）。

**建议修法**（任一即可）：
- 在 `escape_math` / 块渲染阶段**剥离模型自撰的 `\tag{…}`**（编号由渲染期统一分配，符合"渲染期编号"的既有约定）；
- 或检测到 `\tag` 时把该块改用 `equation*`/`align*` 并保留模型给的编号；
- 并在 `tests/test_pdf_compilation.py` 增加一条"含 `\tag` 的公式块仍能编译"的回归。

### R-009【中】失败编译留下的陈旧 PDF 与清单表述不一致

失败编译仍在包内留下 `manuscript.pdf`（**182,215 字节**，mtime 11:49:10），而 `manifest.json` 的
`compilation_status` 为 failed、`pdf` 字段为空。清单表述是**诚实**的（未谎称有 PDF），
但目录里躺着一个不完整的 PDF，单看文件列表会被误导。建议失败时删除或改名为 `manuscript.failed.pdf`。

### R-010【记录】`待定` 占位符 —— 门槛按预期工作

稿件含 5 处 `待定`（`s,d,r 待定`、`q>0, n_ref>0 待定`、`σ_0/M_h/G_c 均待定`），
`publication_gate_reasons` 报"存在未标注的占位符: 待定 ×5"。这属于**门槛正确拒绝**把待定系数当作已定结论交付，
已按"判定为非缺陷"登记；同时说明该题在 S2（无绑定资料）下确实无法闭合到定量结论。

## 3. 值得记录为**正面信号**的三条 blocked 理由

`theory_gate_reasons` 中三条受阻结论给出的理由具体、可复核，且指向同一类错误——
**把定义式或特定极限下的近似式当作一般恒等式使用**：

| 结论 | 系统给出的理由（摘） |
|---|---|
| `clm-683626c580a4` | `p = k_r/(k_r+k_i)` 只是代数定义；要落在 [0,1] 须额外施加 `k_r>0, k_i>0`。变量域未指定（允许 `k_i<0`）时该"概率"可取负值，故"p 是概率"不被证书支撑 |
| `clm-b14e03ea20c9` | 侵入前沿只能写成标度关系 `x_f = sqrt(α·D_eff·t)`（α 为 O(1) 前置因子）；`x_f² = D_eff·t` 一般不成立，故 `D_eff = x_f²/t` 的定量反推不被支撑 |
| `clm-49eb83319ed8` | `D_eff ≡ D_b + f·(D_gb − D_b)` 是定义/假设；写成 `D_eff = D_b + (2δ/g)·D_gb` 不是恒等式，两者相差 `f·D_b` |

正文也自行写明了这一点：*"一个在特定极限下成立的物理近似式，被当作一般恒等式使用时就会把条件性结论升级为无条件结论。"*
这与 `rubric.md` §1.4「局部步骤验证没有被写成整体证明」和 §1.7「写作缺口回流」一致。
