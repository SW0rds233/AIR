# 领域术语表：钙钛矿太阳能电池 · 湿度稳定性

> 由领域侧填写，供人审与运行参照。**本文件只含术语、单位、取值范围与机制关系，
> 不含任何结论**（结论方向、阈值与判定见封存的 `expected_notes.md`）。

## 1. 术语

| 术语 | 说明 |
|---|---|
| 钙钛矿（perovskite） | ABX₃ 结构。光伏语境下 A=MA⁺/FA⁺/Cs⁺，B=Pb²⁺/Sn²⁺，X=I⁻/Br⁻。**注意同名词**：地学/矿物学中的钙钛矿指地幔矿物相，与光伏无关 |
| 水合产物 | 钙钛矿与水结合形成的结晶水合物（一水合物/二水合物等） |
| 分解产物 | 有机阳离子盐流失后残留的无机产物（如 PbI₂ 类） |
| 晶界 | 多晶薄膜的晶粒界面，常为水汽优先侵入路径 |
| 钝化 | 通过添加剂/界面处理减少缺陷态与侵入通道 |
| PCE | 光电转换效率（power conversion efficiency） |
| 效率保持率 | 老化后 PCE / 初始 PCE |
| RH | 相对湿度（relative humidity） |
| 可逆 / 不可逆 | 是否可在给定后处理条件下恢复（**术语标签**，本身不是机制结论；使用时必须写明所指条件） |

## 2. 单位与量纲

| 量 | 单位 | 备注 |
|---|---|---|
| 相对湿度 | %（RH） | 必须与温度同时给出，否则不可比 |
| 温度 | °C | 老化条件 |
| 暴露时长 | h（小时） | 与 RH、温度共同构成条件三元组 |
| PCE / 保持率 | % | 测量口径（扫描方向、稳态）会影响数值 |
| 光照 | mW·cm⁻² 或 sun | 与湿度耦合时须声明 |
| 层厚 / 晶粒尺寸 | nm / µm | 影响侵入路径长度 |

## 3. 典型取值范围（仅作条件书写参照，不构成结论）

- RH：约 10%–90%；极端加速老化可更高
- 温度：约 25–85 °C
- 暴露时长：约 1–1000 h
- 初始 PCE：约 15%–26%（体系相关）
- 判"显著衰减"的常用口径：保持率低于初始值的 80%–90%（**口径须显式声明**）

## 4. 机制关系（关系清单，不指定何者在何区间主导）

- 水汽侵入 → 与钙钛矿发生水合反应 → 生成水合产物
- 水合产物 → 在特定后处理条件下可脱水 → 回到钙钛矿相
- 水合/脱水循环 → 伴随体积变化 → 可能引入不可逆的形貌与缺陷损伤
- 高湿 + 长时间 → 有机阳离子盐流失 → 残留无机产物
- 晶界与针孔 → 水汽优先侵入路径 → 与薄膜质量强相关
- 温度与光照 → 加速上述过程的动力学
- 组分（A 位与 X 位）与添加剂 → 改变水合/分解的相对难易
- 封装与界面层 → 改变实际到达膜的湿气通量
